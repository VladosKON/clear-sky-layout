# Инструкции проекта

- Пользователь предпочитает русский язык, короткие объяснения и выполнение согласованной работы без повторных подтверждений.
- Перед изменениями прочитать `context/PROJECT_CONTEXT.md`. Полная доступная переписка сохранена в `context/CHAT_HISTORY.md`, журналы — в `context/chat-export.json`.
- Главный результат — интерактивная самостоятельная страница `outputs/index.html`. Сохранять офлайн-работу, встроенные ресурсы и компоненты исходного макета.
- Актуальные правки вносить в `work/interactions.js`, `work/page.css` и при необходимости компоненты/сборщик. Не повторять исторические одноразовые скрипты исправлений.
- После правок собрать HTML через `npm run build`, проверить затронутые взаимодействия в браузере и обновить архив `outputs/html-page.zip`.
- Для Figma использовать официальный плагин и соответствующие навыки, сверять конкретные узлы из контекста проекта. Не заменять оригинальные ресурсы произвольными иконками.
- GitHub: https://github.com/VladosKON/clear-sky-layout (публичный), ветка main. После каждой согласованной правки выполнить сборку, проверку, обновление архива, commit и push. GitHub Actions публикует Pages автоматически; проверить успешное завершение workflow и опубликованную страницу. Локальную переписку context/ не публиковать.
- Все файлы новой работы хранить внутри этого проекта. Исходная папка чата оставлена как резервная копия.
