# Макет Чистое небо

Интерактивная самостоятельная HTML-страница настройки оформления Saby по компонентам Figma. Цвета, прозрачность, градиенты, текстуры и настройки расположения сохраняются в браузере. Серверная CRM не подключена.

## Запуск и сборка

Требуется Node.js 24.

```sh
npm run setup
npm run build
```

Откройте `outputs/index.html` в браузере. Все ресурсы встроены, страница работает офлайн.

## Исходники

- `work/interactions.js` — взаимодействия и состояние.
- `work/page.css` — стили.
- `work/*.tsx` — компоненты макета.
- `work/assets/`, `work/icons.json` — оригинальные ресурсы.
- `work/render.cjs`, `work/assemble.cjs`, `scripts/build.cjs` — сборка.
- `work/build/package-lock.json` — зафиксированные зависимости.

Исторические скрипты исправлений в `work/` сохранены для справки; повторно запускать их не нужно.

## Публикация

GitHub Actions собирает и публикует страницу в GitHub Pages после каждого push в `main`. Также можно запустить workflow вручную во вкладке Actions. На сайт выгружается только готовый HTML.

Локальные журналы переписки, кэш и установленные зависимости не входят в публичный репозиторий.
